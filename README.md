# AlgorithmShowcase-main

**Mingwei Zou | Mathematical ideas, computational implementation, visual explanation**

An algorithm portfolio organized around three fundamental design paradigms. Each showcase pairs a demonstration video with an explanation of the problem, the algorithm's decisions, and the evidence used to evaluate its output.

The central question is how a mathematical formulation becomes an executable procedure: what structure the algorithm uses, which decisions it makes, and what those decisions imply for correctness, efficiency, and solution quality.

## From formulation to evidence

Each page follows the same reading order:

1. **Watch the demonstration** — see the output and relevant interactions.
2. **Understand the problem** — identify inputs, objective, and constraints.
3. **Follow the algorithm** — connect its decisions to the implementation.
4. **Evaluate the result** — examine checks, measurements, and limitations.
5. **Reproduce the demonstration** — locate the code, data, and run instructions.

Together, these projects provide concrete examples of mathematical modeling, algorithm implementation, and evidence-based evaluation: foundations for further study in applied mathematics and data science.
